# Our Little Story

A handmade digital scrapbook you can send as a monthsary gift.

## Personalize

Each tab has **one data file**. Edit that file to change that page.

| Tab | File |
| --- | --- |
| Names, dates, song | `src/data/config.js` |
| Photos (shared) | `src/data/photos.js` |
| Beginning | `src/data/beginning.js` |
| Our Story | `src/data/ourStory.js` |
| Timeline | `src/data/timeline.js` |
| Memories | `src/data/memories.js` |
| Little Things | `src/data/littleThings.js` |
| Secrets | `src/data/secrets.js` |
| Letters | `src/data/letters.js` |
| Gallery | `src/data/gallery.js` |
| Things We've Done | `src/data/thingsDone.js` |
| Memory Jar | `src/data/memoryJar.js` |
| Our Months | `src/data/counting.js` |
| One Moment | `src/data/oneMoment.js` |
| Finale | `src/data/finale.js` |

Drop photos into `public/assets/photos/` as `photo1.jpg` … `photo16.jpg`, and your song at `public/assets/music/our-song.mp3`.

## Run

```bash
npm install
npm run dev
```
